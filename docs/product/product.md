# Product Overview: Personal Blog

## Description
Personal blog web application for Mehmet Semih Babacan - a technical founder and entrepreneur. Built with Next.js 15, MDX for content, and Tailwind CSS for styling.

## Current Features

### Pages
- **About** (`/about`) - Personal introduction and background
- **Resume** (`/resume`) - Professional experience
- **Blog** (`/thoughts`) - Blog posts with series filtering

### Blog Features
- **5 Active Posts** in "Founder Insights" series
- **Series Support** - Filter posts by series, colored badges
- **View Counting** - Firebase Realtime Database integration
- **YouTube Videos** - Optional video embeds at post top

### Technical Stack
- **Framework**: Next.js 15 with App Router
- **Content**: MDX files with metadata exports
- **Styling**: Tailwind CSS
- **View Tracking**: Firebase Realtime Database
- **Analytics**: Vercel Analytics & Speed Insights

### Available Series
- `Founder Insights` - Entrepreneurship and leadership (blue)
- `Tech Deep Dives` - Technical explorations (purple)
- `Agentic Coding` - AI-assisted development (green)
